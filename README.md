# 🏠 مشاور هوشمند املاک

## Project Overview

این پروژه یک **مشاور هوشمند املاک** است که مشخصات یک ملک را به زبان طبیعی (فارسی) از کاربر دریافت می‌کند، با استفاده از یک AI Agent ویژگی‌های ملک را استخراج می‌کند، در صورت ناقص بودن اطلاعات ضروری از کاربر سؤال می‌کند، و در نهایت با استفاده از یک مدل Machine Learning از پیش آموزش‌دیده (`house_price_model.pkl`) قیمت تخمینی ملک را محاسبه و به‌صورت قابل‌فهم به کاربر ارائه می‌دهد.

قیمت نهایی همیشه توسط مدل ML محاسبه می‌شود؛ LLM فقط برای فهم زبان طبیعی، استخراج ویژگی‌ها، تشخیص اطلاعات ناقص و توضیح نتیجه استفاده می‌شود و هرگز قیمت را خودش تولید نمی‌کند.

## Features

* AI Agent برای فهم گفتگوی طبیعی و مدیریت conversation
* پیش‌بینی قیمت با Machine Learning (`house_price_model.pkl`)
* استخراج مشخصات ملک از توضیحات آزاد کاربر
* تشخیص اطلاعات ضروری ناقص و درخواست تکمیل آن از کاربر
* در نظر گرفتن امکانات اختیاری ملک (پارکینگ، انباری، آسانسور و ...) در محاسبه امتیاز ملک
* رابط کاربری ساده با Streamlit

## Project Structure

```text
real_estate_agent/
│
├── app.py                  # رابط کاربری Streamlit؛ ورودی کاربر را می‌گیرد و Agent را اجرا می‌کند
├── agent.py                 # منطق کامل Agent: استخراج ویژگی، بررسی اطلاعات ناقص، فراخوانی مدل ML
├── house_price_model.pkl    # مدل آموزش‌دیده پیش‌بینی قیمت (باید در همین مسیر قرار گیرد)
├── requirements.txt          # کتابخانه‌های موردنیاز پروژه
├── .env.example               # نمونه فایل تنظیمات برای API Key
├── .gitignore
└── README.md
```

## Installation

```bash
pip install -r requirements.txt
```

سپس فایل `.env.example` را به `.env` تغییر نام دهید و مقدار `OPENROUTER_API_KEY` خود را در آن قرار دهید:

```text
OPENROUTER_API_KEY=your_api_key_here
```

(به‌جای `.env` می‌توانید از Streamlit Secrets نیز استفاده کنید.)

## Running

```bash
streamlit run app.py
```

## Model

فایل `house_price_model.pkl` مدل آموزش‌دیده پیش‌بینی قیمت ملک است (خروجی یک مدل Gradient Boosting). این فایل باید در همان پوشه‌ی `app.py` و `agent.py` (ریشه پروژه) قرار داشته باشد. مدل در این پروژه دوباره آموزش داده نمی‌شود و فقط برای پیش‌بینی (inference) بارگذاری و استفاده می‌شود.

## Important Note

⚠️ قیمت نمایش‌داده‌شده صرفاً یک **تخمین آماری** بر اساس مدل Machine Learning و اطلاعات واردشده توسط کاربر است و جایگزین قیمت قطعی معامله یا نظر کارشناس رسمی املاک نیست.
